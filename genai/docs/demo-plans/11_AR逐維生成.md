# Demo 11:AR 逐維生成

**檔名** `public/demos/ar-2d-interactive.html`(+ 同名 `.check.mjs`)
**課程位置** 第二堂⑤ AR 段(介面實作頁之後)
**展示的單一概念** chain rule 分解:$\log p(x)=\log p(x_1)+\log p(x_2\mid x_1)$。
logprob 精確、便宜;sample 被迫逐維序列。

## 畫面與互動
- 三個 panel:左為 2D 資料空間(三群高斯混合資料散點 + 已生成點);中為邊際 $p(x_1)$
  直方;右為條件 $p(x_2\mid x_1)$ 曲線(依當前 $x_1$ 即時更新)。
- 模型(不訓練,binned 統計):$x_1$ 離散化為 40 bins 的直方;$x_2\mid x_1\in\text{bin}$
  為該 bin 內樣本的 1D 直方(平滑後)。
- 互動:
  1. 「生成一點(分步)」:先抽 $x_1$(中 panel 高亮該 bin),再抽 $x_2$(右 panel 高亮),
     左 panel 打點;兩步之間有 400ms 動畫延遲,凸顯序列性
  2. 「連續生成」開關
  3. 點左 panel 任意位置:顯示 $\log p(x_1)$、$\log p(x_2\mid x_1)$ 與總和三個讀數
  4. 「維度順序」切換(先 $x_2$ 後 $x_1$):同一點的總 logprob 不變(分解不唯一,密度唯一)
- 讀數列:已生成點數、當前查詢點的三項 logprob。

## 實作要點(Tier 0)
- 純 JS + canvas,無外部依賴;約 300 行
- 核心計算包在 `/* ===CORE:BEGIN=== */ … /* ===CORE:END=== */`,輸出 `CORE` 物件:
  `CORE.fit(data)`、`CORE.logprob(model, x, order)`、`CORE.sampleStep(model, state)`
- `body.embed` 緊湊模式:隱藏 `.sub`/`.notes`,縮小 h1(參照既有 demo 的 CSS)

## 課堂展示腳本(90 秒)
1. 分步生成兩次:第二步的條件曲線隨 $x_1$ 不同而不同(30s)
2. 點兩個位置查 logprob:兩項相加,密度區讀數高、空白區讀數低(30s)
3. 換維度順序,同一點總 logprob 讀數不變(30s)

## 驗收(check.mjs)
- 邊際與各條件直方歸一(±1e-9)
- 兩種維度順序下,數個測試點的總 logprob 一致(±0.15,直方離散化容差)
- 抽 2000 點,三群各自都有樣本(覆蓋性)
