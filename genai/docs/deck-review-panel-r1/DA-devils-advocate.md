## 最強反論(Strongest Counter-Argument)

這份藍圖的核心弱點不是漏抄大綱,而是**只抄了大綱的頁面順序,沒有接手大綱指派給現場講者的工作**。大綱多處明示其編排依賴講者現場補位:黑板角落常駐的介面契約、「每個散度性質兩分鐘內接上學員見過的現象」的教學紀律、開場對照表「講一次、第二堂回放」的口頭鋪陳。藍圖同時又立下「嚴禁預告、嚴禁解釋編排」的最高規格,等於把講者的補位手段也一併沒收,卻沒有以投影片機制(漸進表格、常駐元件、現象例頁)補回來。結果是:頁 3 的對照表在學員的知識狀態下不可讀、第①節 25 分鐘純數學無一個 LLM 現象錨點、DDO 在第 90 分鐘後的注意力低谷登場而回接鷹架全靠 75 分鐘前的一頁。另外,藍圖把 demo 計畫改寫成五個未規格化、未建置的新 demo,並無聲丟棄大綱明列優先序的三個建議 demo,這是對權威文件最實質的偏離。

## 攻擊清單

### 1. [MUST] L1 頁 3:對照表在學員知識狀態下不可讀,且藍圖規格自斷退路

**頁面**:L1 p3(回放於 L2 p42)

第三欄「光譜位置」的內容(「只改 base 項、不動係數」「受 β 約束」「左端的結構後果」「度量工具本身(Appendix D)」)依賴 ②(base/係數)、④(β)、乃至一個藍圖根本沒有排入的模組(Appendix D)。mode-covering / mode-seeking 要到 p10–11 才定義。大綱假設講者口頭帶過並承諾「第二堂回放」;藍圖規格 1 卻嚴禁「之後會講」式的預告,於是這張表在 p3 既不能被理解、也不能被合法地掛起。學員看到的是一整欄未定義符號。

**化解**:p3 只呈現前兩欄(題目、其背後的機率問題),第三欄留空或不出現;L2 p42 回放時才補上完整三座標定位(與 SpectrumRows 的 progressive prop 同一手法,對照表元件加 progressive 屬性即可)。

### 2. [MUST] Appendix D 成為懸空指標:第六個實驗室題目的收尾永遠不會到來

**頁面**:L1 p3、L2 p42;缺頁:全份藍圖

大綱把「信心與正確率」定位為「度量工具本身(Appendix D)」,並在 demo 建議 2、3(calibration scatter、semantic entropy)標明「與實驗室專案直接相關」。藍圖整份沒有 Appendix D 的任何落點:沒有頁面、沒有 demo、沒有告知另辦 workshop 的決策記錄。但 L2 p42 仍承諾「重放實驗室題目對照表,以三個座標系定位」六個題目——第六題的座標指向一個不存在的模組。這不是可延後的裝飾,是收尾論證的一個斷鏈:課程對實驗室的說服力正建立在「每個題目都被理論收編」上。

**化解**:三選一並寫入藍圖:(a) L2 ⑥ 前加 2–3 頁迷你度量段(semantic entropy + calibration,配大綱建議 demo 2/3);(b) 明文決定另辦一小時 workshop,p3/p42 的第六列改寫為不依賴 Appendix D 的表述;(c) 至少在 p42 對第六題給出僅用 logprob 介面語言的定位(「讀出的 logprob 是否可信」),不引用不存在的附錄。

### 3. [MUST] Demo 計畫實質改寫了權威文件:五個未規格化的新 demo,三個明列優先序的建議 demo 全數消失

**頁面**:L1 p24、p35、p44;L2 p7、p21;藍圖「Demo 對應」表

大綱的 demo 計畫只有兩類:三個既有 2D demo(已對號入座)與三個「建議新增 LLM-native demo(依優先序)」——token probability browser(第一優先,明文服務 ①②③「證明 logprob 介面真的存在、係數是光譜座標」)、calibration scatter、semantic entropy。藍圖一個都沒採用,反而發明五個大綱從未提及的 demo(guidance-playground、asr-noisy-channel、mle-vs-ddo-gradient、interface-contract、exposure-bias-track),全部未建置、零規格(展示什麼、可操作什麼、失敗時的靜態備援),卻各佔一整頁課堂時間。這是藍圖對大綱最大的一筆無聲偏離,也是最大的執行風險:九個 demo 中五個不存在。

**化解**:對每個新 demo 補一段規格(展示目標、互動、對應大綱哪個論點、靜態備援圖);逐一交代與大綱建議清單的對應關係(例如 guidance-playground 是否涵蓋 token probability browser 的兩個論證目標,若不涵蓋則優先建置後者);建置不及的 demo 頁預先指定降級為哪張靜態元件圖。

### 4. [MUST] 大綱的教學紀律(「性質兩分鐘內接上見過的現象」)完全沒有落到頁面上:L1 p9–18 是 25 分鐘無錨點的純數學

**頁面**:L1 p9–18(兼及 p2)

大綱 Teaching discipline:「散度必須先是某個問題的答案,才能是定義」「每個性質兩分鐘內連到學員已見過的具體現象」「第一堂所有例子保持 LLM-native」。藍圖第①節 18 頁中,p9–18 沒有任何一個 LLM 輸出現象:沒有 base model 含糊迴避的實例、沒有 aligned model 千篇一律的實例、forward/reverse KL 的失效型態只以抽象詞(over-smoothed、collapse)出現。p2 的課程主張同樣用了要到 p10–11 才定義的詞彙,而學員看不到那兩種現象長什麼樣子。大綱把這件事交給講者,藍圖的「投影片自明」規格(規格 8)卻要求頁面自己承擔,兩頭落空。

**化解**:p10、p11、p18 各加一條現象帶(具體 LLM 輸出對照:forward KL ↔ 泛泛安慰語/hedging,reverse KL ↔ 對齊後回答同質化);p2 或 p3 前插入一頁真實輸出對照(同一問題,base vs aligned 各數則),讓主張先以可觀察的現象出現、再獲得名字。此舉不違反規格 1:呈現現象是學科內容,不是編排後設。

### 5. [SHOULD] AR「改進史與應用」一頁塞入八個里程碑、兩條提速路線、四個應用域,違反藍圖自訂規格 8,且與 DPM 的三頁改進史失衡

**頁面**:L2 p23(對照 p38–40)

大綱給 AR 20 分鐘、且明言 AR 是「實驗室唯一實際接觸的家族」;三難註記要求改進史「逐步問移向哪個頂點、代價為何」。藍圖卻把 n-gram→RNN/LSTM→attention→Transformer→scaling law→instruction tuning/RLHF、speculative decoding、multi-token prediction、四個應用全部壓進 p23 一頁,而 DPM(17 分鐘)的改進史享有 p38、p39、p40 三頁。一頁 Timeline 塞不下「每步對應三難哪個頂點」的分析,只剩年表;這正是藍圖規格 8「一頁裝不下就拆頁」要防的事。

**化解**:p23 拆為兩頁:改進史(Timeline 標注每步的三難頂點,RLHF 一步標明光譜移動)/ 提速路線+應用。VAE p28、GAN p34 同步檢視(見攻擊 6)。

### 6. [SHOULD] GAN p34 一頁承擔三種論證:年表、DDO 單向轉移論證、應用——DDO 回接是論證不是年表項目

**頁面**:L2 p34

「$d^*=p/(p+q)$ 是用自身 logprob 造判別器的原型;轉移單向:判別器想法進入 logprob 家族,反向不可行」是整門課介面論證的收束句之一(大綱在 GAN 段落以獨立段落處理),被藍圖夾在 DCGAN→BigGAN 年表與應用清單中間。學員在同一頁要切換三種閱讀模式,收束句最可能被年表淹沒。

**化解**:DDO 回接獨立成頁(與 L1 p45 的 DPO 對照頁形成結構呼應),p34 只留改進史+應用;或併入 p32(結構極限同構頁)之後,論證歸論證、年表歸年表。

### 7. [SHOULD] SpectrumRows 漸進呈現有斷層:第③節整節沒有畫任何一列,decoding settings 列從未被正式引入

**頁面**:L1 p25、p27–35、p37、p48

大綱 Appendix B:B-0 光譜三列「在第一堂 ②③④ 漸進畫出」。藍圖的 SpectrumRows 出現在 p25(第一列)、p37(第三列起點)、p48(全圖):第③節(p27–35,正是 decoding settings 所屬的段落)一次都沒出現。p48 宣稱「三列完整呈現」,但中間一列從未有自己的登場頁,學員第一次看到它就是在總結頁的完成態。漸進圖的教學價值恰在每列與其段落綁定,藍圖抄了元件卻丟了節奏。

**化解**:p31(temperature/top-p 頁)加 SpectrumRows(第二列);並核對 p25 畫的是哪一列——依大綱行序,②(guidance/decoding)對應第二列,④ 才是第三列,藍圖現標「第一列」「第三列起點」的指派需要重排或說明。

### 8. [SHOULD] 難度峰值落在第 78–110 分鐘的 DDO 推導,藍圖未提供任何常駐鷹架;大綱的「黑板角落常駐契約」沒有投影片對應物

**頁面**:L1 p41–47;p6(ContractCard 僅此一頁)

大綱明文:契約「寫在黑板角落,整堂保留」——這是黑板媒介的持久性,投影片沒有等價物,而藍圖的 ContractCard 只在 p6 出現一次。DDO(p41 起)依賴 p17 的判別器讀法(約 75 分鐘前)與 p23 的表末列;p41 一頁同時給出構造、BCE 最優性與三個「無需」宣稱,p43 是含積分的梯度式,全部落在兩小時課的注意力低谷。大綱選擇 DDO 作壓軸有其論證理由,但它假設講者能即時回指黑板;藍圖把黑板拿掉了,鷹架卻沒補上。

**化解**:(a) ContractCard 降級為常駐頁緣元件(layout 層,每頁角落),兌現「黑板角落」的原意;(b) p41 前插一頁前備回收(僅兩行:p17 的 $d^*$、p23 的表末列,直接陳述結論,不違反規格 1);(c) p41 的三個「無需」宣稱移到 p42 圖頁,讓 p41 只做一個推導。

### 9. [CONSIDER] 兩堂各 120 分鐘,藍圖無任何休息點

**頁面**:L1、L2 全份

大綱對此沉默,但大綱寫給講者、講者會自行喊休息;藍圖是頁級執行規格,不標休息點就等於沒有。L1 的自然斷點在 p26 後(②結束,第 58 分)或 p35 後;L2 在 p13 後(三難結束,第 50 分)。

**化解**:各標一頁休息頁或在藍圖表格加一行 break 註記,並確認前後段落的回接句不跨越休息點。

### 10. [CONSIDER] Appendix A 課前自檢六題被整個丟棄,無任何載體

**頁面**:缺(對照大綱 Appendix A)

reparameterization、Jensen、Gaussian log density 是 L1 p9 起的推導前提,大綱以課前自檢處理;藍圖既無課前發放物、也無首頁連結,前提檢查機制消失。

**化解**:不必進投影片:藍圖「產出物」清單加一份課前自檢 handout(或 L1 p1 附連結),並在藍圖記錄此決定。

### 11. [CONSIDER] 頁數自述不一致:L1 標「約 48 頁」實列 49 頁

**頁面**:藍圖 L1 標題行 vs p48–49

小事,但這份文件是驗收依據,數字應自洽。**化解**:改為 49。

### 12. [CONSIDER] L1 各節時間總和恰為 120 分鐘,零緩衝,而大綱在 p26 處另要求 3 分鐘討論

**頁面**:L1 p26;Appendix C 對照

大綱 ② 的 22 分鐘內含「約 3 分鐘討論」;藍圖 p26 保留了討論內容,但 ② 的 8 頁(含一個 demo 頁)在 22 分鐘內已無鬆動空間,任何 demo 失敗或討論延長都直接侵蝕 ④ 的 DDO 時段(見攻擊 8 的低谷問題)。

**化解**:在藍圖為每節標注可捨頁(例如 p20 動機頁可併入 p21),給講者明確的丟棄順序,而非任由超時向後傳染。

## 被忽略的替代路徑(Non-Defect Observations)

- 候選攻擊「demo 分布頭重腳輕(49 頁第一個 demo 在 p13)」經核算不成立:L1 demo 落在 p13/24/35/44,約每 20–25 分鐘一個,節奏均勻;真正的問題是 demo 的存在性與規格(攻擊 3)與 p9–18 的現象真空(攻擊 4),不是間距。
- 候選攻擊「DDO 佔 12 頁不成比例」不成立:p36–47 十二頁對應大綱明定的 32 分鐘(RLHF 14 + DDO 18),頁時比正常;可攻擊的是低谷時段的鷹架(攻擊 8),不是篇幅。
