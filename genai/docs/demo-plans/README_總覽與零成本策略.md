# Demo 計劃書總覽與零成本策略

配合課程:生成模型入門(兩堂各 2 小時,介面版大綱)
設計前提:全部 demo 以 0 成本展示。分四個成本層級,越前面越優先:

| 層級 | 策略 | 適用 demo |
|---|---|---|
| Tier 0 | 純前端 JS,無模型、無網路 | 01–06 |
| Tier 1 | 瀏覽器內推論(Transformers.js / WebLLM),模型下載一次後離線可用 | 08、10(embedding) |
| Tier 2 | 課前在實驗室機器以 Ollama(免費、本地)預先計算,前端只讀靜態 JSON | 07、09、10(取樣) |
| Tier 3 | 免費雲端 API,僅作為 Tier 1/2 的備援 | 08 備援 |

## 課堂風險原則(三方共識)

教室網路不可靠是常態。Tier 0–2 完全離線可跑;Tier 1 的模型須在課前預先載入瀏覽器快取。
Tier 3 只在「現場臨時要換 prompt 且本地模型跑不動」時使用。

## Tier 3 免費 API 出處(2026-08 查證,額度會變,備課時請再確認)

| 服務 | 免費額度重點 | 注意事項 |
|---|---|---|
| Google AI Studio(Gemini) | 免費層,實際限額以 AI Studio 專案頁為準 | 歐盟/英國/EEA 以外,prompt 會被用於訓練 |
| Groq | llama-3.3-70b:30 RPM / 1,000 RPD | 速度快,適合現場互動 |
| Cerebras | 每日約 1M tokens | 量最大 |
| OpenRouter(:free 模型) | 20 RPM;未儲值帳號每日 50 次 | 一把 key 通多家;logprobs 支援視底層供應商而定 |
| NVIDIA NIM(build.nvidia.com) | 免信用卡 | |
| Hugging Face Inference | serverless 免費層 | text-generation 可回傳 token 細節 |
| Mistral(Experiment tier) | 免費 | 須同意資料用於訓練才可用 |

**關於 logprobs**:雲端免費層對 OpenAI 相容參數 `logprobs` 的支援不一,而本課程多個 demo
恰恰需要完整 logits。因此 logprob 類 demo 一律以 Tier 1(瀏覽器內推論,拿得到全部 logits)
為主方案,雲端只當備援。

## 三方討論角色定義

- **P(教學設計)**:守「一個 demo 只講一個概念」與課程大綱的對應關係
- **E(前端工程)**:守實作成本、離線可行性、行數預算
- **D(課堂演示)**:守 60–90 秒可講完、投影可讀性、失敗備案
