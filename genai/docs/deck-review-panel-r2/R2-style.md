# R2 審查:文風與寫作規格(round 2)

範圍:`lecture-01.md`、`lecture-02.md`,投影片文字與講稿(HTML 註解)皆列入。
依據:`docs/deck-blueprint.md`「最高優先寫作規格」、humanizer-zh-tw 指南。

合規事項先記錄:兩份 deck 均無第二人稱「你」;禁用比喻詞(尺/軸/骨架/骨幹/體質/招牌病)零出現(lecture-02:749「噪聲尺度」、lecture-02:843「時間軸」為字面義,不違規);無破折號連用、無「值得注意的是」式空洞強調、無宣傳語、無 -ing 式附加分析句;主張皆有出處,粗體整體節制;「光譜」「介面」「眾數」「塌縮」「特徵性失效」等核心術語跨兩堂一致。以下為缺失。

## MUST

### 1. lecture-01 可見文字「不是 A,而是 B」句式共 4 處,超過上限 3

規格第 3 條:每份 deck 至多 3 處。lecture-01 投影片文字的正格出現(而是/而非):

- lecture-01:613 「prompt 裡的示範**不**改參數,**而是**收緊模型對『現在在做哪個 task』的後驗」
- lecture-01:619 「記憶系統做的是挑選哪些證據進入後驗,**而非**單純的資料存放」
- lecture-01:673 「非法 token 的機率被精確歸零,**而非**僅僅被勸退」
- lecture-01:1080 「把分布的缺陷藏起來**而非**修好」

另有同族變體(不計入正格,但加重同質感):659「預設值不是答案,兩種錯誤的相對代價才是」、857「並非經驗巧合」、862「約束的是與參考模型的距離,不是多樣性本身」。

四處中對比工作量最低的是 619(「單純的資料存放」是沒有人主張的稻草人)。建議改寫該處以降到 3:

> 修改:「memory agent 的機率語意:記憶系統的工作是**挑選哪些證據進入後驗**;存放只是實作手段。」

或更省:「記憶系統的工作是**挑選哪些證據進入後驗**。」

lecture-02 正格 2 處(392、527)加變體 68(「並非設計偏好:…」),未超限。

### 2. 可見投影片文字上的後設預告,共 5 處

規格第 1 條禁止在投影片預告「稍後/之後會講」。以下皆為可見文字,非講稿:

- lecture-01:294 「對齊與 reverse KL 的關係**在本堂稍後給出**。」
  → 刪去該子句:「對齊後的模型回答收斂到少數幾種安全模板、多樣性下降,是 mode-seeking 目標的行為特徵。」
- lecture-01:392 「同一個式子的另一種寫法,**之後會直接引用**:」
  → 「同一個式子的等價寫法:」
- lecture-01:900 「這個結構極限**稍後還會以另一個身分出現**。」
  → 整句刪除(下一堂自會以 GAN 判別器重現,無需預告)。
- lecture-01:1086 「具體模型家族與數字,**放在各家族的脈絡裡再看才有意義,此處先記結論**。」
  同時觸犯「解釋編排理由」。→ 「量化結果見第二堂表列(Zheng et al., 2025)。」或整段刪除。
- lecture-02:146 「同一列讀水平取捨,同一欄讀家族差異。**接下來三頁分別讀 GAN 列、exact 兩列、多步列。**」
  → 保留第一句,刪除第二句(頁面自己會出現,無需導覽)。

### 3. 講稿中的跨堂預告,2 處

生產規則明定講稿同樣只載學科內容;「第二堂會…」屬明文禁止類型:

- lecture-01:174 「參數法的每一種選擇都犧牲了某些查詢能力,**這是第二堂的主題**。」
  → 「參數法的每一種選擇都犧牲了某些查詢能力。」
- lecture-01:276 「MLE 等價於最小化 forward KL(**交叉熵一節在第二堂 AR 段有完整推導;此處不提**)。」
  → 「MLE 等價於最小化 forward KL。」

## SHOULD

### 4. 講稿內大量「下一頁/下一節/稍後」導覽句

單處輕微,但密度高到成為固定句式,且同屬規格第 1 條禁止的預告類。逐條列出(皆為講稿):

- lecture-01:86–87 「課程結束時回到這一頁,屆時兩個詞各自有數學內容」;148 「這個差別下一頁量化」;194 「之後每一頁右下角都有這兩個介面的徽章」;215 「之後遇到…全部指回這一格」;250 「兩個方向接下來各一頁」;361 「『有界』下一頁馬上變成缺點」;422 「光譜這張圖之後每節補一列」;464 「接下來兩頁只是把常見方法逐一填進三個欄位」;601 「四層各自展開一到兩頁」;767 「右端接下來三頁補上」;825 「這個形狀稍後在 DDO 再出現一次」;851 「結構上的共同點下一頁」;1042 「三列光譜圖,下一節收攏」
- lecture-02:24 「本堂處理具體構造」(前句「第一堂建立了…」為事實陳述,可留);53 「是本堂的組織原則」;75 「幾頁後的矩陣處理」;96 「(GAN 段)就從這裡出發」;127 「GAN 段會看到」;151 「之後每個家族段落開頭都回到它」;171 「下一頁的 Flow 是關鍵對照」;259 「接下來一小時逐家族驗證這張圖」;329 「下一頁正是這個問題」;399 「『下標在 p』下一頁變成問題」;466 「速度角下一頁」;789 「下三頁沿線走」

改法一律相同:刪除導覽子句,把要說的事實直接說完。例 lecture-01:148:

> 修改:「判別式的輸出空間可以列舉,生成式的輸出空間(所有句子、所有影像)不能;量化見 $2^{65536}$ 一例。」

(講稿中的時間標記 [約 N 分鐘] 與 demo 操作腳本屬演示指令,不在此列。)

### 5. lecture-01:209–210 投影片上的前瞻宣告

> 「$p_{\text{data}}$ 缺 `logprob` 這件事**貫穿整門課**…**後面每一個**『算不出來』的量,**追到底都是這一格**。」

「貫穿整門課」「後面每一個」是對課程結構的預告,不是學科事實。改為現在式的一般陳述:

> 修改:「資料給的是樣本,沒有密度;凡是需要 $p_{\text{data}}$ 密度的量,都卡在這一格。」

### 6. 大陸慣用技術詞,zh-TW 應改

- 「噪聲」→「雜訊」:lecture-01:710(「p(audio|text)」上下文)、715 「噪聲通道模型」、734(demo 標題「噪聲通道」);lecture-02:750–751 「噪聲尺度」「純噪聲」、754 「預測噪聲」、480 「噪聲通道的 prior 項」。台灣通行「雜訊通道」「雜訊尺度」「加入雜訊」。
- 「信噪比」→「訊噪比」:lecture-02:763。
- 「量綱」→「因次」(或白話「單位」):lecture-02:365 「量綱與 tokenizer 無關」→「單位與 tokenizer 無關」。

### 7. 統一引導式的名稱在四種說法間循環

同一條式子跨兩堂被稱作:「引導生成的統一形式」(lecture-01:457 頁標)、「統一式」(lecture-01:530、545、927、1047、1061)、「統一引導式」(lecture-02:23、607、809)、「guidance 統一式」(lecture-02:164)。這是 humanizer 指南的同義詞循環。建議:頁標保留全名「引導生成的統一形式」,行文一律「統一引導式」,「統一式」「guidance 統一式」全數替換。

### 8. 抽樣/取樣、前向/前傳不一致

- lecture-01:659 「取樣設定」為全課唯一「取樣」,其餘皆「抽樣」(lecture-01:45、47、1103;lecture-02:252、776 等)→ 統一「抽樣」。
- lecture-02:514 「decoder 一次**前傳**」vs. lecture-02:300 「一次**前向**即得」、776 「一步一次前向」、856 「每步兩次前向」→ 統一「前向」(首次出現可寫「前向傳遞」)。

### 9. 口語比喻密度過高的兩處

- lecture-01:329–331(同一頁連續兩個):「forward KL 是唯一『**介面帳單付得起**』的散度」「reverse KL 與 JSD 都**撞上同一堵牆**」。
  → 修改:「forward KL 是唯一所需介面皆可得的散度:期望用 $p_{\text{data}}$ 的樣本近似,被積函數只呼叫 $p_\theta$.logprob。reverse KL 與 JSD 缺的是同一個介面:$p_{\text{data}}$ 沒有 logprob。」
- lecture-01:673 「在 prompt 裡**懇求**格式」「而非僅僅被**勸退**」:擬人化口語,且與第 1 項的句式超限同句。
  → 修改:「這比在 prompt 裡以指示要求格式可靠:非法 token 的機率被精確歸零,軟性指示做不到這一點。」(順帶消去一處「而非」。)

## CONSIDER

### 10. 金句式收束

lecture-01:869 「這是一個旋鈕,兩個願望。」、lecture-01:962 「同一著棋,下在不同的棋盤。」皆為可引用金句(humanizer:聽起來像金句就重寫)。兩句各自確實承載對比內容,教學上有記憶點,保留可辯護;若收斂,962 可改「DPO 與 DDO 的參數化手法完全平行,套用的目標不同」,869 可改「安全與多樣由同一個 $\beta$ 控制,無法分開調。」

### 11. 粗體標籤+冒號條列的機械重複

lecture-01:673–677(**constrained decoding / grammar**:…/**logit bias**:…/**contrastive decoding、DoLa、CFG for LLM**:…)、lecture-01:526–530(三個結論,每條粗體整句起頭)、lecture-02:163–166(1. **訓練只能經過判別器代理**:…)。單頁看是正當的投影片慣例,連續多頁同構即成 AI 模式。可留標籤、改為不粗體,或改其中一頁為散文句。

### 12. 三項排比

lecture-02:979 「無需額外判別器網路、無需交替訓練、無需對抽樣過程反向傳播。」講稿(982)自陳「三個『無需』對照傳統對抗訓練的三大負擔」,內容驅動、可留;但同堂尚有「三個散度,三種補法」「三件事」「三個結論」(lecture-01)等標題級的三,整體偏公式化,新增內容時避免再湊三。

### 13. 個別搭配不自然

- lecture-01:640 「**取用**正確率明顯下降」→「答對率明顯下降」或「檢索命中後的答對率」。
- lecture-02:165 「任何密度**簿記**的約束」→「不受可逆性、序列分解或任何密度正規化要求的約束」。
- lecture-01:830(頁標)「reward model 的介面**身分**」→「reward model 補的是哪一格」。

### 14. 休息頁的預告

lecture-01:577 「回來之後:同一條式子在系統裡的四個安裝位置」、lecture-02:271 「回來之後:逐家族檢視…」。嚴格讀是「預告之後會講」,但休息頁性質上是議程資訊;若從嚴,直接刪副標,只留「休息 10 分鐘」。

### 15. 講稿與 demo 標題的口語詞

講稿:lecture-01:738 「腦補」、lecture-02:789 「主線任務」、828 「原產地在此」——講稿是口語底稿,可留;demo 標題 lecture-02:223 「對每個家族按按看」出現在可見畫面,與全課書面語體有落差,可改「逐家族呼叫兩個介面」。
