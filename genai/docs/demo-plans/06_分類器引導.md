# Demo 06:Classifier Guidance

> 沿革:此位置原為「噪聲通道 ASR 組合器」。ASR 的貝氏拆法只在 GMM-HMM / hybrid 成立,
> 端到端 ASR 直接建模 $p(y|x)$,該範例於 2026-08-24 整頁換成 classifier guidance,
> 舊 demo(asr-score-fusion)已移除,可自 git 歷史取回。

**課程位置** 第一堂③ 第 3 層(引導的具體例子,接第②節統一引導式)
**展示的單一概念** $\log p_w(x)=\log p(x)+w\log p(c|x)$:分類器就是比值項,
$w=0$ 無條件、$w=1$ 貝氏後驗、$w>1$ 外插。

## 畫面與互動
- 三個面板:無條件分布 $p(x)$、分類器 $p(c|x)$(含 0.5 決策邊界)、引導後 $p_w(x)$ 與 250 個樣本
- 控制:類別 A/B/C 三顆按鈕、guidance scale $w\in[0,4]$ 滑桿、樣本顯示開關
- 讀數:格點熵、目標類別質量、$\|p_w-p(\cdot|c)\|_1$(在 $w=1$ 歸零)
- 底部:與 Demo 01 統一式的欄位對照

## 實作要點(成本 0,Tier 0)
- 三個各向異性高斯的混合,密度、後驗、引導後分布全為解析解,不需訓練
- 全程 log 空間:$\log p_w=\log p+w\log p(c|x)$,logsumexp 求 $\log p$,$w$ 拉到 20 也不溢位
- 等價寫法 $p_w\propto p^{1-w}(\pi_c N_c)^w$ 供 check 交叉驗證

## 課堂展示腳本(120 秒)
1. $w=0$:右圖等於左圖,目標類別質量 = 該類別先驗(15s)
2. $w=1$:L1 距離歸零,這就是貝氏後驗(30s)
3. $w=3\sim4$:樣本雲縮小、熵下降、類別質量升到九成以上,保真度換多樣性(45s)
4. 換成先驗 0.20 的類別 C:同一根 $w$,窄類別被拉起的幅度更明顯(30s)

## 驗收標準(`classifier-guidance.check.mjs`)
- $w=0$ 與無條件分布逐點相同;$w=1$ 與 $p(x|c)$ 逐點相同(誤差 < 1e-15)
- 恆等式 $\log p(c|x)=\log p(x|c)-\log p(x)+\log\pi_c$
- 幾何內插寫法與分類器寫法一致
- $w$ 增大:熵單調下降、目標類別質量與 $E[\log p(c|x)]$ 單調上升
- L1 距離以 $w=1$ 為谷底;$w=20$ 不出現 NaN/Inf
