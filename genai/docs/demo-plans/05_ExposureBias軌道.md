# Demo 05:Exposure bias 軌道模擬

**課程位置** 第二堂⑤ AR 段(即板書 B-2 的動態版)
**展示的單一概念** 訓練軌道(前綴來自 $p$)每步誤差固定;自由生成軌道誤差隨步數複合。

## 設計目標
把 $\mathrm{KL}(p\|q)=\sum_t\mathbb{E}_{x_{<t}\sim p}[\cdot]$ 的下標問題變成兩條肉眼可見
的分岔軌道,並解釋 memory agent 長對話漂移。

## 畫面與互動
- 5 狀態 Markov chain(天氣圖示:晴/多雲/雨/雷/雪),真實轉移矩陣 $P$,模型 $Q=P+\varepsilon$
- 上軌道(teacher forcing):t=1..30 每步顯示邊際分布色條,前綴永遠依 $P$ 演化
- 下軌道(free-running):前綴依 $Q$ 演化,色條逐步偏離
- 每步下方各一根小柱:上軌為單步條件 KL(恆定),下軌為邊際 TV 距離(遞增)
- 控制:擾動 $\varepsilon$ 滑桿、步數滑桿、重設

## 實作要點(成本 0,Tier 0)
- 全部用轉移矩陣冪精確計算邊際,無取樣雜訊;約 250 行
- 版面刻意做成「兩條軌道自左端分岔」,與板書 B-2 同構

## 課堂展示腳本(90 秒)
1. ε 調小:兩軌道幾乎平行,單步 KL 柱很矮(20s)
2. ε 稍增:上軌柱高不變,下軌 TV 柱逐步墊高(40s)
3. 提問:「訓練目標量測過下面這條軌道的任何一步嗎?」→ 帶回下標 $x_{<t}\sim p$(30s)

## 三方討論紀錄
- E:原案用字元級 n-gram 現場訓練,雜訊大且慢。改用解析 Markov chain,結果乾淨。
  **決議:解析計算。**
- P:單步柱與累積柱的量綱不同(KL vs TV),並排會被誤讀。**決議:兩軌道各用自己的
  指標並明確標名,附一行說明為何下軌用 TV(邊際比較)。**
- D:30 步太長投影看不清,預設 15 步、滑桿上限 30。**決議:採納。**
- P:加一顆「切到 memory agent 情境」按鈕,把狀態換成對話主題標籤,連回實驗室題目。
  **決議:做成第二組 preset,不改核心邏輯。**

## 驗收標準
- ε=0 時兩軌道完全一致;ε>0 時上軌單步 KL 恆定、下軌 TV 單調遞增
- 兩組 preset(天氣/對話主題)切換正常
