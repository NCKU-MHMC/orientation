# Demo 02:MLE vs. DDO 梯度場

**課程位置** 第一堂④(總結案例 DDO)
**展示的單一概念** MLE 只在資料點上推高;DDO 多一股在 $p_\theta > p_{data}$ 處壓低的力。

## 設計目標
把 DDO 梯度式 $\nabla_\theta L=\int(1-d_\theta)(p_\theta-p_{data})\nabla_\theta\log p_\theta$
的「推高/壓低」變成看得見的箭頭場與訓練動畫。

## 畫面與互動
- 左右並排兩個 1D 畫面(64 bins):左 MLE、右 DDO。$p_{data}$ 為雙峰(灰色實線),
  $q_\theta=\text{softmax}(\theta)$ 為可訓練分布(amber 面積)
- 每個 bin 上畫梯度箭頭:向上 amber、向下 cyan。左畫面永遠沒有 cyan 箭頭,這就是重點
- 控制:播放/暫停/重設、學習率滑桿、「self-play:每 N 步更新 $p_{ref}$」進階開關
- 讀數:forward KL 與 reverse KL 各自的即時值(兩畫面同步顯示)

## 實作要點(成本 0,Tier 0)
- 1D 類別分布的梯度可手寫解析式,不需要自動微分函式庫;約 250 行
- 初始 $q$ 刻意在雙峰之間放多餘質量,讓 DDO 的壓低箭頭第一眼就出現
- $p_{ref}$ 預設固定為初始 $q$;self-play 開關開啟後每 50 步複製當前 $q$

## 課堂展示腳本(90 秒)
1. 先看左畫面播放:MLE 收斂,但峰間殘留質量退得很慢(30s)
2. 右畫面播放:cyan 箭頭把峰間質量往下壓,reverse KL 讀數下降明顯快於左側(40s)
3. 停格提問:「左畫面裡,有任何機制知道中間那塊質量是多餘的嗎?」(20s)
