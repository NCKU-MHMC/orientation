## 0. 課程定位

這門課不是生成模型通識,是**實驗室現有研究的底層說明書**。骨幹不是模型分類法,而是散度 —— 因為分類法只給學生一張清單,散度給的是可推導的因果。

### 論題(第一堂第 10 分鐘提出,第二堂最後一頁回收)

> **base model 的空泛 hedging,與對齊後模型的千篇一律,是同一條軸的兩端。**

### 敘事骨幹(四步)

1. 生成 = 讓 $p_\theta$ 逼近 $p_{\text{data}}$。但「逼近」需要**一把尺**
2. 尺不只一把,而且不對稱 → **選尺 = 選你願意犯哪一種錯**(mode-covering vs. mode-seeking)
3. 尺**能不能算**,決定它變成哪一個演算法家族 —— 全課骨架
4. 訓練結束後分布就定了,但你要的往往不是它 → **引導生成 = 在同一條軸上滑動**

### 貫穿全課的那條軸

```
mode-covering ←─────────────────────────────────→ mode-seeking
涵蓋全部,糊                                        銳利,可能漏

訓練目標   forward KL · MLE    JSD · GAN     reverse KL · RLHF
解碼設定   溫度 T > 1          T = 1         top-p 收緊、CFG↑
權重微調   SFT · 仍是 MLE                    DPO / DDO · β 小
```

第一堂末尾只畫最上面一列,第二堂再補下面兩列。學生會親眼看到:**下面兩列是上面那一列的推論時版本與權重版本。**

### 開場對照表(第一堂 ① 放一次,第二堂 ⑥ 回收)

| 實驗室題目 | 它其實是什麼機率問題 | 在軸上的位置 |
|---|---|---|
| prompt engineering | 選擇條件變數 $c$,操控 $p(y \mid c)$ | 只換 base,不動係數 |
| memory agent | 條件集合的建構;長 context 下 $p(\text{task} \mid \text{prompt})$ 被稀釋 | 同上 |

## ② 生成 = 分布逼近,而逼近需要一把尺(35 分)

### 起點

- 生成 = 從 $p(x)$ 取樣;為什麼高維的 $p(x)$ 不能直接建表
- 目標是讓 $p_\theta$ 逼近 $p_{\text{data}}$ —— 但「逼近」不是一個唯一定義的動作

### KL 的不對稱

$$\mathrm{KL}(p\|q)=\int p\log\frac{p}{q}$$

積分的權重是 $p$,所以**只在 $p$ 有質量的地方追究責任**。

- **Forward KL** $\mathrm{KL}(p_{\text{data}}\|p_\theta)$:$p>0$ 而 $q\to0$ 處罰無限大 → $q$ 必須蓋住 $p$ 的全部 support → **zero-avoiding / mode-covering**
- **Reverse KL** $\mathrm{KL}(p_\theta\|p_{\text{data}})$:權重換成 $q$,$p$ 的其他模式被忽略也不會被罰 → **zero-forcing / mode-seeking**

> **配圖 B-1**:單峰 $q$ 擬合雙峰 $p$。forward KL 蓋住全部並在峰間搭橋;JSD 折衷;reverse KL 鎖定單峰。

### JSD:三個必須澄清的點

$$\mathrm{JSD}(p\|q)=\tfrac12\mathrm{KL}(p\|m)+\tfrac12\mathrm{KL}(q\|m),\quad m=\tfrac{p+q}{2}$$

1. **JSD 不是對稱化的 KL。** 對稱化 KL(Jeffreys)$=\mathrm{KL}(p\|q)+\mathrm{KL}(q\|p)$ 繼承兩邊的無限大,support 不重疊時就是 $\infty$。JSD 因為分母換成混合分布 $m$,**永遠有界**:$0\le\mathrm{JSD}\le\log 2$,且 $\sqrt{\mathrm{JSD}}$ 是真正的距離度量
2. **JSD 在中間,但比較「軟」。** 兩種懲罰都有,但都被 $m$ 壓在 $\log 2$ 以下。support 不重疊時立刻飽和 → 梯度消失 → 原始 GAN 的病理,也是 non-saturating loss 與 WGAN 的動機
3. **JSD = 判別器詮釋。** 最佳判別器 $D^*=\frac{p}{p+q}$ 下,GAN 目標值 $=2\,\mathrm{JSD}(p\|q)-2\log 2$。JSD 就是「一個最佳分類器能多好地分辨樣本來自誰」,等於 $I(X;Z)$,$Z\sim\text{Bernoulli}(1/2)$

### 本段的核心訊息

> **選尺 = 選你願意犯哪一種錯。** 沒有中立的尺。

| | Forward KL | JSD | Reverse KL |
|---|---|---|---|
| 行為 | mode-covering | 中間、但飽和 | mode-seeking |
| 對稱 | 否 | 是 | 否 |
| 上界 | 無 | $\log 2$ | 無 |
| 失敗長相 | 糊、hedging、什麼都想蓋 | 梯度消失或震盪 | 塌縮、多樣性喪失 |

### 課後練習(不佔課堂時間)

用單一高斯擬合 1D 雙峰混合,分別最小化三個散度,數值求解 $\mu,\sigma$。做過一次就不會再搞混。

## ③ 尺的可計算性決定演算法家族(25 分)

**這是全課骨架,也是本次改版新增的關鍵段。**

| 尺 | 需要什麼 | 拿得到嗎 | 於是變成 |
|---|---|---|---|
| forward KL | 從 $p_{\text{data}}$ 取樣 + 算 $p_\theta$ 密度 | 都拿得到 | MLE → AR / VAE / DPM |
| reverse KL | 從 $p_\theta$ 取樣 + 算 $p_{\text{data}}$ 密度 | **後者拿不到** | 需要 reward / energy 代打 → VI、RLHF |
| JSD | 兩邊密度都要 | 都拿不到 | 只能繞道訓一個判別器 → GAN |

> **講完這句學生對三家的關係就永久定型:GAN 的判別器不是設計上的巧思,是計算上的必然。**

延伸一句,替第二堂鋪路:reverse KL 那一列的「reward 代打」與 GAN 那一列的「判別器代打」,其實是同一件事的兩種說法 —— 兩者都在補一個拿不到的 $\log p_{\text{data}}$。

## ④ 家族巡禮:每家的招牌病都是它那把尺的性質(40 分)

### AR / LLM(約 20 分,本段重點)

**它是 forward KL 的直接產物。**

$$\log p(x)=\sum_t \log p(x_t \mid x_{<t})$$

**CE 與 KL 的關係**

$$H(p,q)=-\mathbb{E}_{x\sim p}[\log q(x)]=\underbrace{H(p)}_{\text{與 }\theta\text{ 無關}}+\mathrm{KL}(p\|q)$$

- **分類**:目標是 one-hot,$H(p)=0$,所以 CE **就是** forward KL,一絲不差。一旦目標變軟(label smoothing、蒸餾),兩者才分家
- **$H(p)$ 消不掉**:$H(p)=-\mathbb{E}_{x\sim p}[\log p(x)]$,$\log$ 裡是 $p$ 自己,只有樣本沒有密度 → 無法蒙地卡羅估計。這正是 ③ 那張表裡「$\log p_{\text{data}}$ 拿不到」的另一面
- **四條實務路徑**:① 讓它成為共享常數(在同一份資料上比差值)② 相對於參考模型正規化 ③ 用已知 $H(p)$ 的合成資料 ④ 繞開 likelihood(MAUVE / MMD / 下游指標)
- **跨 tokenizer → bits per byte**:鏈鎖法則會 telescope,字串的 log-likelihood 與怎麼切 token 無關,會變的只有分母

$$\mathrm{BPB}=\frac{T}{N_{\text{bytes}}}\cdot\log_2 \mathrm{PPL}_{\text{token}}$$

  三個必查 caveat:tokenizer 要無損(`decode(encode(s)) == s`);算的是 canonical 切法,是真實字串機率的**上界**且不同 tokenizer 鬆緊不同;固定 chunking、stride 與 BOS 處理

**鏈鎖分解與 teacher forcing**

$$\mathrm{KL}(p\|q)=\sum_t \mathbb{E}_{x_{<t}\sim p}\Big[\mathrm{KL}\big(p(\cdot\mid x_{<t})\,\big\|\,q(\cdot\mid x_{<t})\big)\Big]$$

**請學生盯著期望值下標:$x_{<t}$ 取自 $p$,不是 $q$。** 三個結論:

1. **teacher forcing 不是訓練技巧,是 forward KL 分解式的字面實作**
2. **exposure bias 在同一行式子裡**:推論時前綴來自 $q$,但訓練目標從未測量過任何模型自己生成的前綴 → 訓練與推論優化的不是同一個泛函 → memory agent 的長對話漂移
3. **把下標從 $p$ 換成 $q$,就得到 reverse KL 的分解** → scheduled sampling / RL / DPO / DDO 的共同點不是「用了 RL」,而是「把 loss 搬到了下方軌道」

> **配圖 B-2**:兩條軌道分岔圖(訓練軌道水平、推論軌道逐步下沉,標註「訓練 loss 只在上面這條軌道上計算」)

**forward KL 在 token 層級的實作機制**

語料裡每個前綴通常只有一個續寫,所以每個位置的目標是 one-hot,是高變異但無偏的估計;模型能收斂到條件分布,是因為 CE 是 proper scoring rule。後果是:**模型永遠不會把任何 plausible token 壓到 0(懲罰是 $+\infty$)**。

→ 往下推一步就是虛假前提:**用 forward KL 訓練的模型,結構上就沒有「拒絕回答」這個選項,除非後訓練另外教它。** $p(y\mid x)$ 良好定義與 $x$ 值得被回答,是兩件完全不同的事。

**其他必講細節**:tokenization 讓機率被切碎(confidence 估計最常踩的坑);序列 likelihood 的長度偏誤與正規化。

### VAE(約 7 分)

forward KL + ELBO。糊來自高斯 likelihood(= MSE)。潛在變數與邊際化的符號要留下 —— 第二堂 ICL 與 semantic entropy 要用。

### GAN(約 8 分)

**JSD 是理論,實務用的不是 JSD。**

$2\,\mathrm{JSD}-2\log 2$ 只在最佳判別器下成立,而那正是梯度消失的地方。改用 non-saturating loss 後,對應的散度變成

$$\mathrm{KL}(p_g \| p_{\text{data}}) - 2\,\mathrm{JSD}(p_g \| p_{\text{data}})$$

第一項是 **reverse KL** —— mode-seeking 的來源;第二項帶負號 —— 訓練不穩的來源。

| | 原始 minimax | non-saturating |
|---|---|---|
| 對應散度 | JSD(對稱) | reverse KL $-$ 2·JSD |
| 病理 | 梯度消失,學不動 | mode-seeking,會塌縮 |

> **GAN 的兩種 loss 分別坐在兩種失敗模式上。你為了修梯度消失而換掉的那個 loss,順手把 mode-covering 也換掉了。**

**mode collapse 的四層原因**(不必全講,但要點出第一層):

1. **生成器的 loss 裡沒有資料。** $\mathbb{E}_{p_{\text{data}}}[\log D(x)]$ 不含 $G$;而 $D(x)$ 是**逐點**判斷,「覆蓋度」是分布層級性質,判別器的介面裡沒有這個欄位
2. non-saturating loss 已含 reverse KL(上表)
3. min-max 沒有位能函數 → 繞圈 → mode hopping;$D$ 會遺忘,塌縮後沒有回頭的力
4. 一步生成的幾何代價:蓋住單一模式的映射既平滑又便宜,塌縮是低成本解

**Demo 操作(5 分)**:高斯混合 ×6 訓練到 collapse → 打開「左圖疊上 D 地景」→ 問學生:**畫面上有任何東西告訴你「有兩群被漏掉了」嗎?** 答案是沒有。被漏掉的那幾群在地景上是亮的,而生成點看不見那份亮度。這個「亮著但沒人去」的畫面是最好的 mode collapse 註腳。

### DPM / Flow(約 5 分)

forward KL 的另一種分解:沿噪聲尺度拆,而非沿序列拆。訓練目標退化成簡單回歸,所以與 AR 一樣穩定。此處只要建立「同一把尺、不同分解方式」的印象,細節留給自修。

# 第二堂(120 分):在軸上滑動 —— 引導生成

## ① 訓練結束了,但分布不是你要的(10 分)

回顧第一堂:訓練選了一把尺,尺決定了模型分布長什麼樣。現在模型固定了,而你要的分布往往不是它 —— 你要更銳利、要符合某個條件、要更安全、要更多樣。

**引導生成 = 在同一條軸上滑動。** 補上軸的下面兩列作為本堂路線圖。

保留六層階梯作為目錄(不再是骨架):

| 層 | 介入點 | 手段 | 本堂段落 |
|---|---|---|---|
| 1 | 改條件 $c$ | prompt、few-shot、RAG、memory | ③ |
| 2 | 改取樣 | temperature、top-k/top-p/min-p、beam | ③ |
| 3 | 改 logits | logit bias、constrained decoding、contrastive decoding、DoLa、CFG for LLM | ③ |
| 4 | 改樣本聚合 | self-consistency、best-of-n、MBR、reranking | ③ |
| 5 | 改權重 | SFT、LoRA、RLHF / DPO、**DDO** | ④ |
| 6 | 改表徵 | activation steering、representation engineering | ④ |

## ② 對數空間的統一形式(25 分)

**本堂的收斂點。** 幾乎所有引導手法都可以寫成

$$\log p_{\text{guided}} \;=\; \log p_{\text{base}} \;+\; w\,\big(\log p_A - \log p_B\big) \quad(\text{再 renormalize})$$

| 手法 | base | 比值項 | 係數 |
|---|---|---|---|
| temperature | $\log p$ | — | 整體乘 $1/T$ |
| CFG | $\log p(x\mid c)$ | $\log p(x\mid c)-\log p(x)$ | $w$ |
| contrastive decoding / DoLa | $\log p_{\text{strong}}$ | $\log p_{\text{strong}}-\log p_{\text{weak}}$ | $\lambda$ |
| Autoguidance | $\log p_\theta$ | $\log p_\theta-\log p_\phi$ | $w$ |
| RLHF 最優解 | $\log \pi_{\text{ref}}$ | $r(y)$ | $1/\beta$ |
| DDO 最優解 | $\log p_{\text{ref}}$ | $\log p_{\text{data}}-\log p_{\text{ref}}$ | $1/\beta$ |

top-k / top-p 是同一方向的**硬截斷**版本 —— 不連續,但同樣把質量從尾巴移走。

**三個一次講完的結論:**

1. **係數就是那條軸上的座標。** $w$ 或 $1/\beta$ 越大,越往右。所有旋鈕是同一個旋鈕
2. **推論時做與訓練時做的差別只有「什麼時候做」。** DDO 把 guidance 烘進權重,所以推論成本不變 —— 這是表格的直接推論,不需另外解釋
3. **prompt engineering 只換 base 那一項,不動係數。** → **多樣性問題與過度銳化問題,寫再多 prompt 也修不好,因為 prompt 根本不在那個位置上**

第 3 點請留 3 分鐘讓學生消化,這是整門課對他們日常工作最直接的一擊。

## ③ 推論時滑動:第 1–4 層(30 分)

### 第 1 層 · 改條件

- **prompt = conditioning**。ICL 作為隱式貝氏推論:$p(y\mid\text{prompt})=\int p(y\mid\text{task})\,p(\text{task}\mid\text{prompt})\,d\,\text{task}$
  - → memory agent 的理論框架:記憶不是「存資料」,是「**選擇哪些證據進入後驗**」
  - → 條件加得越多不一定越好:無關 context 讓 $p(\text{task}\mid\text{prompt})$ 變糊(lost-in-the-middle、position bias)
- RAG(顯式條件)vs. fine-tune(攤提進權重的條件)的機率意義與失效模式

### 第 2 層 · 改取樣

- temperature 是 logits 除以 $T$,直接調整分布的熵;top-p 是截斷後重新歸一化
- 情感支持系統該用什麼設定?低 $T$ 安全但單調,高 $T$ 有溫度但風險上升 —— **這是設計選擇,不是預設值**

### 第 3 層 · 改 logits

- **constrained decoding / grammar**:在合法 token 子集上重新歸一化 —— 結構化輸出的正確做法,比在 prompt 裡拜託模型輸出 JSON 可靠得多
- **contrastive decoding / DoLa / CFG for LLM**:影像圈的 CFG 與 LLM 的對比解碼是 ② 那張表裡的同一行

### 第 4 層 · 改聚合

- best-of-n / MBR / reranking = 用樣本重估分布
- **LLM-ASR 專段**:$p(\text{text}\mid\text{audio})\propto p(\text{audio}\mid\text{text})\,p(\text{text})$ 就是噪聲通道模型,而且它本身就是對數空間的線性組合
  - n-best rescoring 與 LLM 糾錯 = 第 4 層
  - speech encoder 接進 LLM = 第 1 層(把聲學表徵當條件)
  - 傳統 ASR 的「LM weight + insertion penalty」本質上就是 ② 那個係數 $w$ 的手動版;改用 BPB 尺度可讓超參數在換 LM 後仍大致可移植

## ④ 權重裡滑動:第 5–6 層(35 分)

### SFT → RLHF / DPO(約 15 分)

- SFT = 在新資料上重做 MLE,**仍在軸的左端**
- **RLHF 目標** $\max_\pi \mathbb{E}[r(y)]-\beta\,\mathrm{KL}(\pi\|\pi_{\text{ref}})$
  - 閉式解 $\pi^*\propto\pi_{\text{ref}}\exp(r/\beta)$ —— 正是 ② 表格的一行
  - 優化過程等價於最小化 $\mathrm{KL}(\pi\|\pi^*)$ —— **reverse KL**
  - 「對齊後模型變安全但變無聊」不是副作用,是目標函數的數學後果,$\beta$ 就是那個旋鈕
  - 對情感支持系統:**安全性與回應多樣性是同一個 $\beta$ 的兩端**
- **與 GAN 同構的盲點**:$\mathbb{E}_{y\sim\pi}[r(y)]$ 也是只在模型自己樣本上取的期望值,而 reward model 也是**逐點評分器** —— 它永遠不會說「你的回應分布太窄了」。唯一擋著塌縮的是 $\beta$ 那個錨,而它錨的是「別離參考模型太遠」,不是「保持多樣性」。LLM-as-judge 有一模一樣的盲點
- activation steering(第 6 層)一頁帶過

### Capstone:DDO(約 15 分)

**接法:承接第一堂 ④ 那張分岔圖的懸念。**

1. 回放分岔圖,提問:要怎麼讓下方軌道也被測量?(2 分)
2. 三個答案並列:scheduled sampling、RL/DPO、**DDO**。共同點是負向訊號來自模型自己生成的樣本(2 分)
3. DDO 的兩行推導 + 機制圖(5 分)
4. $\beta<1$ 的 overshoot = 訓練時的 guidance(3 分)
5. 兩個「負面」結果(3 分)

**兩行推導**

GAN 的最佳判別器 $d^*(x)=\dfrac{p_{\text{data}}}{p_{\text{data}}+p_{\theta_{\text{ref}}}}=\sigma\!\left(\log\dfrac{p_{\text{data}}}{p_{\theta_{\text{ref}}}}\right)$

既然 likelihood-based 模型本來就能算 $\log p_\theta(x)$,那就令 $d_\theta(x):=\sigma\!\left(\log\dfrac{p_\theta(x)}{p_{\theta_{\text{ref}}}(x)}\right)$,再用**標準 GAN 判別器 BCE loss** 訓練它。最佳解落在 $p_\theta=p_{\text{data}}$。

不需要額外判別器網路、不需要交替訓練、不需要對取樣過程反向傳播(對迭代取樣的擴散與 AR 模型特別關鍵)。

> **配圖 B-3**:真實樣本 + 參考模型樣本 → 隱式判別器 $\sigma(\beta\log p_\theta/p_{\text{ref}})$ → 判別 loss;虛線回饋:每輪參考模型 ← 本輪最佳模型(self-play)

**梯度形式 —— 與 MLE 最鮮明的對比**

$$\nabla_\theta L=\int (1-d_\theta(x))\big(p_\theta(x)-p_{\text{data}}(x)\big)\nabla_\theta \log p_\theta(x)\,dx$$

在 $p_\theta<p_{\text{data}}$ 處推高、相反處壓低。**對照:MLE 只會在資料點上「推高」,從來沒有任何機制去「壓低」模型自己亂放的機率質量。**

**DDO 在軸上的定位(本次改版的新論述)**

它的 loss 同時含 $\mathbb{E}_{p_{\text{data}}}[\cdot]$ 與 $\mathbb{E}_{p_{\text{ref}}}[\cdot]$ —— **既有 forward KL 的推高力,也有 reverse KL 的壓低力**。所以它不是軸上的某一點,而是**唯一一個同時抓住兩端的方法**。這讓它從「一篇很酷的論文」變成整條軸的收束。

**與 DPO 的關係**

| | DPO | DDO |
|---|---|---|
| 隱式參數化 | reward $=\beta\log\frac{\pi_\theta}{\pi_{\text{ref}}}$ | discriminator $=\sigma(\beta\log\frac{p_\theta}{p_{\text{ref}}})$ |
| 目標 | 偏好學習 | 分布對齊 |
| 資料 | 成對人工標註 | 原始訓練資料,與模型樣本不需配對 |
| 優化什麼 | winner 與 loser 的機率差距 | 整個分布向 $p_{\text{data}}$ 對齊 |

**與 guidance 的關係**

加入 $\alpha,\beta$ 後(必要,因為 $\log p_\theta$ 量級可達 $10^3$,直接餵 sigmoid 會梯度消失),最佳解為 $p_\theta^*\propto p_{\text{ref}}^{1-1/\beta}\,p_{\text{data}}^{1/\beta}$ —— 正是 ② 表格的最後一行。

> **可以寫在黑板上:guidance 是推論時的銳化,DDO 是把同一件事烘進權重裡。**

**實驗結果**

- guidance-free FID:EDM2-L (ImageNet 512) 1.96 → 1.26;EDM2-S (ImageNet-64) 1.60 → 0.97;EDM (CIFAR-10) 1.97 → 1.38 / 1.85 → 1.30
- VAR-d30 guidance-free 4.74 → 1.79,勝過原始 VAR 用了 CFG 的 1.90,推論成本減半
- 每輪 fine-tune 不到 1% 的預訓練 epoch

**兩個更有教學價值的「負面」結果**

1. 繼續用原本 MLE loss 訓練不但沒改善,反而退化 → 不是超參數問題,是 forward KL 目標本身到頂了。「換目標函數 ≠ 調參」最有說服力的實證
2. 原始 VAR 的數字靠 top-k / top-p 取樣得到,這些啟發式實際上在人為降低溫度,引入訓練-推論落差 → **用 decoding 參數把分布截窄,是在掩蓋模型分布本身的缺陷,而不是修好它**

**三個要誠實講的 caveat**

1. $\alpha,\beta$ 需要 grid search(論文每輪約 20 節點掃 $\alpha\in[0.5,50]$、$\beta\in[0.01,0.1]$)
2. $\beta<1$ 時最佳解不是 $p_{\text{data}}$ 而是其銳化版 → **銳度換多樣性的取捨仍在,只是換了位置發生**;FID 本來就偏好銳化。對情感支持題目,同樣的旋鈕該往哪邊撥未必一樣
3. divergence bound 需要 $\log\frac{p_{\text{ref}}}{p_{\text{data}}}$ 與 $\log\frac{p_\theta}{p_{\text{ref}}}$ 有界 → 只在短時間微調時合理,正好呼應 DPO 裡 $\beta$ 的角色

### 收束:似然比是重複出現的原語(約 5 分)

$\log\frac{p_\theta}{p_{\text{ref}}}$ 在六層階梯裡出現三次:

| 層 | 它叫什麼 | 用在哪 |
|---|---|---|
| 3 · 改 logits | contrastive decoding、DoLa、CFG for LLM | 推論時即時相減 |
| 4 · 改聚合 | likelihood-ratio reranking、n-best rescoring | 重排候選 |
| 5 · 改權重 | DPO 的隱式 reward、DDO 的隱式判別器 | 烘進參數 |

**回收第一堂 ④**:那個「相對於參考模型正規化」以消掉 $H(p)$ 的量,就是 $\log\frac{p_\theta}{p_{\text{ref}}}$。它天生扣掉了「這筆資料本身有多難」。

> **現成的 research idea**:用一個小 reference model 做似然比校準,看它與 accuracy 的相關度是否勝過原始 sequence log-prob。

## ⑤ 你滑到哪了?—— 量測(15 分)

**本段的角色:你動了分布,你得知道自己動到哪去了。**

1. token prob → sequence logprob → 長度正規化,各自在測什麼
2. **predictive entropy 的失效**:「巴黎」與「法國巴黎」是兩個 token 序列但同一個語意
3. **semantic entropy**:先按語意聚類再算熵。它天生不受 tokenization 影響 —— 這是它被低估的優點
4. **self-consistency = 蒙地卡羅估計** $p(a\mid q)=\sum_r p(a\mid r,q)p(r\mid q)$ —— 「多跑幾次投票」不是工程 trick,是邊際化
5. **verbalized confidence 為什麼常常不準**:問到的是被 RLHF 塑形過的表面行為,不是底層機率
6. **校準工具**:reliability diagram、ECE、temperature scaling
7. 回收第一堂的 BPB:跨模型比較請用 bytes 當分母;多選題評估再加一層 PMI 正規化 $\log p(a\mid q)-\log p(a)$
