# Demo 12:Normalizing Flow 可逆變換

**檔名** `public/demos/normalizing-flow-2d-interactive.html`(+ 同名 `.check.mjs`)
**課程位置** 第二堂⑤ NF 段
**展示的單一概念** 可逆變換 + 變數變換公式:
$\log p_x(x)=\log p_z(f^{-1}(x))+\log\lvert\det J_{f^{-1}}(x)\rvert$。
sample 一步;logprob 精確;代價是每層必須可逆且 Jacobian 可算。

## 畫面與互動
- 三個 panel:左為 $z$ 空間(標準 Gaussian 等高線 + 座標網格);中為變形過程
  (網格沿層逐步變形);右為 $x$ 空間(資料散點 + 密度熱圖,由反向變換 + log-det 算出)。
- 模型:3–4 層仿射 coupling(RealNVP 型,scale 用 tanh 夾住),參數寫死為對雙月牙資料
  預先擬合好的值(可另附「重新訓練」按鈕以 forward KL 做即時梯度下降,非必要)。
- 互動:
  1. 「層深」滑桿 $t\in[0,L]$:網格與熱圖沿層插值,呈現連續變形;網格不撕裂、不重疊
     即可逆性的視覺形式
  2. 「sample」:抽 $z$,畫出 $z\to x$ 的一步映射軌跡(沿層折線)
  3. 點 $x$ 空間查 logprob:顯示 base 項 $\log p_z$ 與 $\log\lvert\det J\rvert$ 兩項與總和
  4. 「可逆性驗證」:對隨機 200 點計算 $x\to z\to x$ 的最大 round-trip 誤差並顯示
- 讀數列:當前層深、查詢點的兩項 logprob、round-trip 誤差。

## 實作要點(Tier 0)
- 純 JS + canvas;約 350 行;`CORE` 物件包 `forward(z)`、`inverse(x)`、`logprob(x)`、
  `logdet(x)`,置於 `===CORE:BEGIN/END===` 區塊
- coupling 層實作:一半維度不動、另一半做 affine(由不動半邊經小 MLP 或多項式給出
  scale/shift);2D 情形交替遮罩
- `body.embed` 緊湊模式同既有 demo

## 課堂展示腳本(90 秒)
1. 拉層深滑桿:Gaussian 網格連續變形成雙月牙,無撕裂(30s)
2. sample 一步,對照 AR demo 的逐維動畫(20s)
3. 點查 logprob:兩項分解;熱圖即密度,精確可算(40s)

## 驗收(check.mjs)
- round-trip $x\to z\to x$ 最大誤差 < 1e-6(200 隨機點)
- `logdet` 與數值 Jacobian 行列式一致(數點,±1e-3)
- 密度網格積分 ≈ 1(±3e-2)
